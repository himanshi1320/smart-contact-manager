# ConnectHub – Contact Management System

## Overview

ConnectHub is a full-stack contact management application that enables users to securely store, organize, and manage personal and professional contacts.

## Features

* Google OAuth2 Authentication
* Role-Based Access Control
* Contact CRUD Operations
* Search, Pagination, and Sorting
* Profile Image Management
* User Profile Management
* Secure Session Management

## Tech Stack

* Java
* Spring Boot
* Spring Security
* OAuth2
* Hibernate/JPA
* MySQL
* Thymeleaf
* Maven

## Architecture

Controller → Service → Repository → MySQL

## Key Implementations

* Secure user onboarding through Google OAuth2 integration.
* MVC-based application architecture with separation of concerns.
* ORM-based database interactions using Hibernate/JPA.
* Advanced contact management with search, pagination, sorting, and profile image handling.
